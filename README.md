# 🏆 Competition Hunter

An Agentic AI system that searches for current competitions and hackathons and recommends the best ones based on the user's profile.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_LINK
cd competition-hunter
2. Install the Required Packages
pip install -r requirements.txt

3. Add Your API Keys

Create a file named .env inside the competition-hunter folder.

Paste the following:

OPENROUTER_API_KEY=PASTE_YOUR_OPENROUTER_API_KEY_HERE
TAVILY_API_KEY=PASTE_YOUR_TAVILY_API_KEY_HERE

Replace the above values with your own API keys.

4. Run the Project
python main.py
5. Enter Your Details

The program will ask for:

Your skills
Your interests
Your experience level
Your participation preference

The agent will then search for competitions, verify them, and recommend competitions that match your profile.

🔑 API Keys Required

This project requires:

OpenRouter API Key
Tavily API Key
